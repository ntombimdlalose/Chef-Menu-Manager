Chef Menu Manager

Mobile Application

Chef Menu Manager is a mobile application developed to help a chef manage menu items. It allows the user to add, view, edit, update, delete, search and filter dishes, as well as view statistics about the menu.

Features

- Add menu items with a dish name, description, course and price.
- Edit and update existing menu items.
- Delete menu items after confirming the action.
- Search for dishes by name.
- Filter dishes by course: Starter, Main Course or Dessert.
- Clear the search and filter to display all menu items.
- Display the total number of menu items.
- Calculate the average price of all menu items.
- Count the number of items in each course.
- Display menu items in a two-column grid.
- Validate required fields and prices.
- Show feedback messages when items are added or updated.
